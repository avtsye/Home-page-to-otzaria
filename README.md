# דף הבית לאוצריא

תוסף דף בית מודרני לאוצריא, המבוסס על ה־Plugin API הרשמי של התוכנה.

התוסף מחליף את חוויית "הכרטיסייה החדשה" בדף בית שימושי: חיפוש ספרים ותוכן, המשך קריאה, סימניות, היסטוריה, תוספים מותקנים, מועדפים וקבוצות ספרים — והכול בעיצוב שמתאים אוטומטית לערכת הנושא של אוצריא.

## מה יש בתוסף

- חיפוש חי בשמות ספרים ובתוכן הספרייה, באמצעות אותו מנוע `search.query` של אוצריא.
- חיפוש מתקדם עם מצב מדויק/מתקדם/מקורב, מיון, מרחק מילים, תחום קירבה, התאמת מילים, איחוד תוצאות, שלילה, תקופות, ספרי יסוד ואפשרויות מילה.
- פתיחת החיפוש המובנה של אוצריא עם הגדרות החיפוש הפעילות.
- "המשך לקרוא" וספרים שנפתחו לאחרונה.
- סימניות והיסטוריה אחרונה.
- הצגת כל התוספים המותקנים, כולל מצב, גרסה ואייקון המבוסס על `toolTabIconName`; בהיעדר אייקון מוצג סמל אוצריא.
- מועדפים וקבוצות ספרים מותאמות אישית.
- הוספת ספר לקבוצה ישירות מתוצאות החיפוש.
- הגדרות לכרטיסים שיופיעו בדף ולסדר שלהם.
- הגדרה של מספר הפריטים שיופיעו בכל רשימה.
- התאמה אישית של קיצורי הפעולות המהירות.
- בחירת ההתנהגות של לחצן `+` באוצריא:
  - **דף הבית** — ברירת המחדל.
  - **ספרייה** — התנהגות ברירת המחדל של אוצריא.
  - **עיון** — מעבר למסך העיון.
- דיווח על תקלה והצעת רעיון דרך `feedback.report` הרשמי של אוצריא.
- התאמה אוטומטית לערכת הצבעים ולגופן הממשק של אוצריא.
- שמירת העדפות וקבוצות באמצעות `storage.*` של אוצריא.

## דרישות

- אוצריא בגרסה `0.9.97` ומעלה.
- התמיכה בלחצן `+` מותנית במימוש `plugin.setNewTabPage` בגרסת אוצריא שבה משתמשים.

## התקנה

1. הורידו את הקובץ הארוז האחרון מתוך `dist/` או מ־Artifacts של GitHub Actions.
2. התקינו אותו כמקובל בתוספי אוצריא.
3. פתחו את התוסף פעם אחת.
4. לחצן `+` יפתח כברירת מחדל את דף הבית.

הקובץ הארוז הנוכחי:

`dist/home-page-to-otzaria-3.2.0.otzplugin`

## הגדרות לחצן +

פתחו את גלגל השיניים בפינה העליונה של דף הבית ובחרו מה ייפתח בלחיצה על `+`.

כאשר נבחרת **ספרייה**, התוסף מבטל את רישום עצמו כיעד הכפתור ואוצריא חוזרת להתנהגות המובנית שלה.

כאשר נבחר **עיון**, התוסף משתמש במנגנון הכרטיסייה החדשה ואז מעביר למסך `reading`. הסיבה לכך היא שה־API הנוכחי של `plugin.setNewTabPage` מאפשר רישום של דף תוסף או חזרה ל־fallback המובנה של הספרייה, אך אינו מקבל יעד מובנה שרירותי.

## דיווח על תקלה והצעת רעיון

בפס העליון קיימים שני כפתורים:

- **תקלה** — נשלח כ־`reportType: "bug"`.
- **רעיון** — נשלח כ־`reportType: "other"`.

השליחה מתבצעת דרך `feedback.report`. אוצריא מציגה למשתמש דיאלוג אישור לפני השליחה, ויכולה לשמור דיווח בתור לשליחה מאוחרת במקרה שאין חיבור.

## פיתוח

הקוד אינו משתמש בספריות צד שלישי. כדי לבדוק את קובץ ה־JavaScript:

```bash
node --check main.js
```

כדי לארוז ידנית, יש ליצור ZIP שבו `manifest.json`, `index.html` ו־`main.js` נמצאים בשורש הארכיון, ואז לשנות את הסיומת ל־`.otzplugin`.

## אריזה אוטומטית

במאגר קיים GitHub Action שבכל `push` ו־`workflow_dispatch`:

1. בודק את `manifest.json`.
2. מריץ `node --check` על `main.js`.
3. יוצר חבילת `.otzplugin`.
4. מעלה אותה כ־Artifact של הריצה.

## סטטוס

הפרויקט נמצא בפיתוח פעיל. הצעות ורעיונות יכולים להישלח ישירות מתוך התוסף.


## אייקוני תוספים

`plugin.listInstalled` מחזיר את שם אייקון הלשונית (`toolTabIconName`) ולא קובץ SVG/PNG. דף הבית מציג אייקון חזותי בהתאם לשם שהוחזר. כאשר אוצריא מחזירה את fallback הרשמי `puzzle_piece_24_regular` עבור אייקון חסר או לא מוכר, מוצג סמל אוצריא הרשמי.

## משוב למפתח

המניפסט מציין את המחבר כ־**אברהם mch**. `feedback.report` עצמו נשלח לאתר אוצריא עם מזהה התוסף, ושם האתר מנתב את הדיווח לבעל התוסף הרשום במערכת.
