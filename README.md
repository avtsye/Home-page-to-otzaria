# דף הבית לאוצריא

תוסף דף בית מתקדם לאוצריא, המבוסס על ה־Plugin API הרשמי.

גרסה נוכחית: **4.0.4**

**תיאור קצר לחנות:** דף בית מתקדם לאוצריא עם חיפוש בתוכן, המשך קריאה, סימניות, מועדפים, קבוצות, תוספים והתאמה אישית מלאה.

## מה יש ב־4.0

### חיפוש
- חיפוש חי משולב: שמות ספרים + תוצאות מתוך תוכן הספרים.
- שימוש ישיר ב־`search.query` וב־`search.getOptions`.
- מצבים: מדויק / מתקדם / מקורב.
- מיון, מרחק מילים, תחום קירבה, התאמת מילים, שלילה, תקופות, ספרי יסוד, איחוד תוצאות ואפשרויות מילה.
- תוצאות עם מראה מקום, קטע טקסט והדגשת המילים שנמצאו.
- ספירות לפי ספר ו־facets מהירים.
- חיפוש בתוך קבוצה מותאמת אישית.
- חיפוש בתוך הספר הפעיל.
- היסטוריית חיפושים מתוך אוצריא.
- שמירת פרופילי חיפוש לשימוש חוזר.
- פתיחה בחיפוש המובנה של אוצריא עם ההגדרות הרלוונטיות.

### דף הבית והתאמה אישית
- Drag & Drop לסידור כרטיסי דף הבית.
- הצמדת כרטיס לראש הדף.
- הסתרת כרטיס ישירות מהכרטיס.
- רענון נקודתי לכל כרטיס.
- תצוגת זמן עדכון.
- מצב Focus שמציג כמעט רק את החיפוש.
- מצב קומפקטי.
- 1 / 2 / 3 עמודות.
- גודל כרטיסים.
- רקע Aurora / עדין / שטוח.
- צבע הדגשה מותאם אישית.
- רדיוס פינות משתנה.
- התאמה טובה יותר לערכת נושא כהה.
- שמירת מצב הממשק בין פתיחות.

### ספרים, קבוצות ומועדפים
- מועדפים וקבוצות ספרים.
- צבע ואייקון לכל קבוצה.
- תתי־קבוצות (קבוצה תחת קבוצה) וסידור סדר הקבוצות.
- העברת ספרים בין קבוצות ב־Drag & Drop.
- חיפוש בתוך קבוצה.
- הצמדת קבוצה כקיצור מהיר.
- הצמדת הספר הפעיל לדף הבית.
- פתיחה חכמה של ספר שכבר פתוח: התוסף מנסה להפעיל את הטאב הקיים במקום ליצור כפילות.
- "המשך לקרוא" מציג את מיקום הקריאה האחרון כשאוצריא מספקת אותו.

> אחוז התקדמות אמיתי בספר אינו מוצג כרגע, מפני שה־API הנוכחי אינו מספק אחוז קנוני ואמין לכל סוגי הספרים.

### תוספים
- הצגת כל התוספים שמוחזרים מ־`plugin.listInstalled`.
- גרסה, מצב, מקור ואייקון.
- fallback לסמל אוצריא כאשר אין אייקון תקין.
- סינון לפי שם.
- מיון לפי שם / פעילים / מועדפים / שימוש אחרון.
- מועדפי תוספים.
- תצוגת כרטיסים או רשימה קומפקטית.
- טעינה עצלה של אזור התוספים.
- תוספים מועדפים יכולים להופיע גם כקיצורים מהירים.

### ביצועים
- cache בזיכרון בלבד עם TTL קצר.
- ללא שימוש ב־localStorage.
- טעינה עצלה של חלקים כבדים.
- Skeleton loading בזמן רענון.
- ניהול DOM שמרני יותר.

### אבחון ויציבות
- לשונית **אבחון** בתוך ההגדרות.
- בדיקות זמינות ל־API מרכזיים.
- דוח אבחון שניתן להעתיק.
- יומן Debug פנימי.
- טיפול גלוי בשגיאות אתחול.
- בדיקות smoke אוטומטיות ב־GitHub Actions.
- בדיקות תחביר ל־`main.js`, `features.js` ולקובץ הבדיקות.
- בדיקה שכל ID שהקוד הראשי מחפש אכן קיים ב־HTML.
- בדיקה מפורשת נגד התקלה הישנה שבה `clone` נקרא לפני הגדרתו.
- שכבת הפיצ'רים המתקדמת נמצאת ב־`features.js`, בנפרד מליבת `main.js`, כך שכשל בפיצ'ר מתקדם יהיה קל יותר לאבחון.

### משוב
בתוך **הגדרות → משוב** ניתן לשלוח:
- תקלה.
- רעיון / משוב אחר.

בנוסף ניתן לבחור קטגוריה:
- כללי.
- חיפוש.
- תצוגה.
- כפתור +.
- תוספים.
- ביצועים.

לפני השליחה מצורף דוח טכני לא־אישי שכולל גרסאות, פלטפורמה, זמינות API ומצב אבחון. אוצריא עצמה מציגה למשתמש חלון אישור לפני שליחת `feedback.report`.

### כפתור +
ניתן לבחור מה ייפתח בלחיצה:
- דף הבית.
- ספרייה.
- עיון.

התוסף נשאר רשום ל־`plugin.setNewTabPage` בכל שלושת המצבים, כדי שכפתור ה־`+` לא ייעלם. כאשר נבחר יעד מובנה, התוסף מנתב אליו לאחר אירוע `plugin.page_opened`.

### קיצורי מקלדת
- `Ctrl+K` — מעבר לחיפוש.
- `Ctrl+,` — פתיחת ההגדרות.
- `Esc` — סגירת חלונות / הצעות.
- `Alt+F` — הפעלה או ביטול של Focus Mode.

### Changelog ואודות
- חלון "מה חדש" מופיע פעם אחת לאחר שדרוג גרסה.
- לשונית "אודות" כוללת גרסה, מחבר וקישור למאגר.
- בדיקת גרסאות חדשות נעשית דרך דף `dist/` במאגר; אין כרגע API רשמי של אוצריא שמאפשר לתוסף לבצע בדיקת עדכון עצמאית מול GitHub מתוך ה־WebView.

## דרישת גרסה

חבילת ה־Release דורשת **אוצריא 0.9.98 ומעלה**. הדרישה מכוונת כדי שחנות התוספים לא תציע את התוסף לגרסאות ציבוריות שעדיין אינן כוללות את ה־API שעליו הוא נשען.

לבדיקות מול build פיתוח שמכיל את ה־API אך עדיין מזדהה כ־0.9.97, GitHub Actions מייצר גם חבילת `-dev-compat.otzplugin`. חבילה זו מיועדת לפיתוח בלבד, אך נשמרת גם ב־`dist/` כחלק מארכיון כל הגרסאות של הפרויקט.

## פיתוח ובדיקות

בדיקות מקומיות בסיסיות:

```bash
node --check main.js
node --check features.js
node tests/smoke.js
```

GitHub Actions מבצע את הבדיקות, אורז את התוסף, מעלה Artifact, ושומר את חבילת ה־Release גם תחת `dist/`. בנוסף נבנית חבילת `-debug.otzplugin` שפותחת אוטומטית את מסך האבחון ומריצה בדיקות API.
